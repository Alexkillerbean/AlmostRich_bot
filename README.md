# Бот «Почти Богат»

Выдаёт доступ к мини-аппу «калькулятор стоимости жизни» по подписке на канал.

## Запуск

1. Скопируйте `.env.example` в `.env` и заполните три значения:
   - `BOT_TOKEN` — токен от @BotFather (BotFather → /newbot);
   - `CHANNEL_ID` — `@username` канала или числовой ID `-100xxxxxxxxxx`;
     бот должен быть **администратором** этого канала;
   - `WEB_APP_URL` — публичный HTTPS-адрес мини-аппа.
2. `pip install -r requirements.txt`
3. `python bot.py`

## Важно про токен

- `.env` в репозитории быть не должно. В git живёт только `.env.example` с заглушками.
- Если токен когда-либо попадал в открытый доступ (коммит, скриншот, переписка) —
  отзовите его в @BotFather (`/revoke`) и сгенерируйте новый.
- Данные пользователей (SQLite, `bot.db`) тоже не коммитить — там реальные id.
